# Horizon - Elevate Your Style (E-Commerce Dashboard)

A modern admin dashboard for managing products, categories, and inventory with dark mode support.

## Features
- ✅ Admin Authentication (Supabase)
- ✅ CRUD Products (Create, Read, Update, Delete)
- ✅ Image Upload with Supabase Storage
- ✅ Category Management
- ✅ Dark / Light Mode

## Tech Stack
- React + Vite
- Tailwind CSS
- Supabase
